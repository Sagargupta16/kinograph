# Troubleshooting

What an error, a rejected file or an odd result means, and what to do. The first table is by symptom; the platform notes and the lessons from past builds follow it.

| Problem | What to do |
|---|---|
| No ffmpeg on the machine (`run_all.py` prints `NO_FFMPEG`; `qa.py: no ffmpeg on PATH (nor in /opt/homebrew/bin or /usr/local/bin)`) | Do not stop. Offer to install ffmpeg (Windows: `winget install Gyan.FFmpeg`; macOS: `brew install ffmpeg`; Linux: the distribution's package, for example `sudo apt install ffmpeg` on Debian and Ubuntu), then open a new shell so PATH is read again. If the installed build has no libx264 (`ffmpeg -hide_banner -encoders` does not list it), use rung b (PNG frames, then AV1 MP4 or VP9 WebM through the colour chain, `engine.md`); make a GIF preview (rung c) if nothing else works. Tell the user which rung and that older QuickTime may not play AV1 or VP9. Every gate module finds ffmpeg as run_all.py does (PATH, then `/opt/homebrew/bin`, then `/usr/local/bin`); one kept anywhere else must be on PATH. |
| A fact or a media file is needed mid-build | Render scripts download nothing. Fetch facts with the agent's web tools first and ask the user for any media, then pass the files in. Everything else (frames, synthesized audio, encode) works offline. |
| `PROOF: NOT CHECKED (n)` or `QA: NOT CHECKED (n)` (exit 2) | A gate had nothing to look at where something was expected. Read each NOT CHECKED row's fix: add `text_items(t)` (Q200, Q205, Q206, Q209), name the cues `CUES` (Q902; cues kept under any other name are not read), rebuild a cue sheet that lost its stems (`run_all.py audio`), or declare `NO_TEXT`, `NO_CUES` or `SILENT` when there is none by design. It is not a pass: `run_all.py` rejects the file. |
| `NOT CHECKED Q100 <module> raised <Error> at <file>:<line>: ...; its gates did not run` | A gate module crashed; the other modules still ran. Import the module and call its `check_rows` alone to see the traceback. `qa.py: <module> did not import (...)` on stderr means its flags or subcommands are missing too. |
| `REJECTED out.rejected.mp4: Q502 FIX, ...` | The file failed those rows and is never delivered. Fix each one (the row's fix after `->`; `qa.py owner --t <worst_t>` names the scene function to re-read), then run again: `run_all.py audio` for an audio-only fix, `full` for a visual one. |
| `UNCHECKED out.unchecked.mp4: the run broke before the QA verdict (the error follows)` | A crash is not a verdict. Fix the error printed after it and run the stage again. |
| `ffmpeg stopped after 53 of 225 frames (exit 0): ...` | ffmpeg's own exit code and first log lines: read them (a bad option, a full disk, a frame it could not take). No partial `video.mp4` is left. |
| `ValueError: frame 5 (t 0.167 s) is 1922x1080; the build is 1920x1080` | draw(t) returned the wrong size at that frame (one such frame shears every frame after it). Return `finish(img)`, which scales to `E.W x E.H`. |
| `ffmpeg exited 0 but logged errors: ...` | Treated as a failed render (a short buffer, a bad packet). Fix what the log names. |
| `note: frame 40 drawn again after OSError: [WinError 1450] ...` | The system was short of resources for a moment (several builds at once); the frame was drawn again and the render went on. Six refusals of one frame, or `write to ffmpeg failed while it was running (frame k of n, 40 retries)`, stop it: run fewer builds or fewer processes at once (`run_all.py full 4`). |
| `video.mp4 predates scenes.py: frame 0 (0.00 s) and 8 more of 9 checked differ ...` or `video.mp4 was rendered at ...` (from `run_all.py audio`) | The picture is from another state of scenes.py, or another size: run `run_all.py full`, or give `audio` the same `--size`, `--fps` and `--ss` as the render. |
| `true peak still over -1 dBTP after 3 re-masters: lower the hits Q802 names` | Lower the raw gain of the sounds the Q802 row lists at that moment, first in its cut order. A lower ceiling makes the limiter work harder (Q805), so it is not the fix (`sound.md`). |
| `a 0.05 MB budget leaves no video bitrate for 7.5 s with 320 kb/s of audio` | The budget cannot hold the audio for that length. Raise it, shorten the piece, or ask where the file goes and what its real limit is (`formats.md`). |
| `--redraw needs --keep-frames ...` or `frames/ lacks 195 of the frames to reuse ...` | Run `run_all.py full --keep-frames` once with no `--redraw`; then `--keep-frames --redraw T0-T1` redraws one passage. |
| `warning: STATIC (0.333333, 1) s moves (frame 20 differs from frame 10): every frame of it is drawn` | That span is not static. Take it out of `STATIC` or narrow it to frames that truly hold. |
| `qa.py purity` NOT CHECKED: `timed out after 240 s`, or `the pool pass waited 240 s for one frame (a worker died or hung)` | An environment failure (memory, a dead worker), not code to fix: report the command and that line. |
| `REFUSED: ...` or `CANNOT APPROVE: ...` from `qa.py approve` | It refuses a missing review, REVIEW FIX, a proof-stage review, a review of another file or of a file written at another time, and a qa.json with FIX or NOT CHECKED rows; it cannot approve without frames.hash from this source and size. Fix the cause and approve again; `--override "<why>"` only with a reason the user accepts (it is recorded and shown by every check). |
| `NOT CHECKED Q1304 environment changed since approval ...` or `DIFF: NOT CHECKED (could not compare ...)` | The frame size changed, or a Python, Pillow, numpy or font change moved frames: review the film in full, then approve again. |
| `refused: . holds a build (...)` from `qa.py calib` | Run it in its own folder (the default `calib/`). |
| `SELFTEST: FAIL (...)` | A gate no longer catches its planted fault (`MISSED`, `WRONG`), or a code is unproven (`MISSING`, `EMPTY`, `UNCOVERED`, `ERROR`): the line names the code and the fixture. Do not trust that gate on a build until it passes again. Every fixture `MISSING` means the engine copy lacks `qa_fixtures/` (copy it with `cp -r engine/. <folder>/`). |
| `Q1105 FIX` on a file encoded by hand (rung b) | The `thumbs.npy` and `frames.hash` in the folder belong to an earlier `full` render, not to this file. Move them out of the folder, then check again (on 2026-10-31 a stale pair turned an AV1 check into a false FIX). |
| A text-to-speech download link expired | Generate the line again and save the file to the working folder as soon as it is ready. |
| `voice engine kokoro-ts is not ready (...). Missing: ...` | The narrator's model files are not in `~/.cache/praxinoscope/voices` (or `$PRAXINOSCOPE_VOICES`). Ask the user before the download, naming the files, their source, sizes and licence (`voice.md`); meanwhile offer music with captions, or SAPI on Windows for a timing draft. Say plainly that there is no natural voice yet and why. |
| Only the SAPI fallback is ready (robotic), or `voice engine kokoro is not ready (UNTESTED ...). Missing: ...` | SAPI is for timing drafts only, and only on Windows. Offer `voice_samples.py` so the user can pick a natural voice once its files are there; kokoro and piper are written but untested. |
| `sapi wrote unusable audio: L02 (<path>.wav, deleted, not cached): no speech above -48.0 dBFS ...` | The engine wrote silence for that line (SAPI does for "..."): fix the line's text. Nothing was cached, so the next run asks the engine again. |
| `word_cue: 'square' is in L02, which has no word times ...`, `... is not in the narration ...; close words: ...` or `... has a time shared out between its neighbours ...` | Use an engine with word times (sapi, kokoro-ts) or cue the line start; fix the spelling from the close words; cue a word the voice says alone, or pass `est=True` knowing the time is a guess. |
| The voice reads names wrongly | Respell phonetically in the voice text only; keep the correct spelling on screen; ask the user to check those lines. |
| `FileNotFoundError: engine.font: no file in FONT_BOLD exists and opens (...)` | No file in `engine.FONT_BOLD` (or `FONT_REG`) exists and opens on this machine. The lists hold Arial on Windows, Arial or Helvetica on macOS, and Liberation Sans or DejaVu Sans in the usual Linux folders; the error itself names the packages (Debian and Ubuntu: `apt install fonts-liberation fonts-dejavu-core`; Fedora: `dnf install liberation-sans-fonts dejavu-sans-fonts`). Ask before installing anything. Or find a font that is there: Windows keeps them in `C:/Windows/Fonts`; macOS in `/System/Library/Fonts`, `/System/Library/Fonts/Supplemental` and `/Library/Fonts`; on Linux `fc-list : file` lists every installed font file. Put the nearest match first in both lists in the working copy of `engine.py`, and tell the user which font the video uses. There is no silent fallback, on purpose (lesson 2 below). |
| Render is slow | Frames are drawn in parallel and piped into the encode; the draw is the cost (3 ms to about 360 ms a frame). Proof first at the real size; for a quick look render a slice (half size, `--fps 15`, or a 5 s passage) and check that. Draw at `SS 1` and supersample only the scenes with thin lines, cache static backgrounds as images, declare true holds in `STATIC`, keep grain and blur out of the preview, and keep the frames (`--keep-frames`) when passages will be redrawn. |
| Run times out | The full render is one call: frames go straight into one encode, so it cannot be split into batches. Time a slice first, give the call a timeout that covers the whole film, and if a tool limit cannot, stop and report it; never deliver a partial file. With `--keep-frames` a rerun redraws only the passages given with `--redraw`. |
| Out of disk or memory | Check `shutil.disk_usage`. Frames are on disk only with `--keep-frames` (about 1.3 GB per 60 s at 1080p); delete `frames/` once the file is verified. For memory, run fewer processes (`run_all.py full 4`) or a lower SS; a memory squeeze during the render redraws that frame. |
| Encode result fails a gate | Change one thing at a time: loudness (`audio.master`, Q805), size (CRF, a budget or resolution), duration (fix DURATION or the scene lengths), then run again and measure. Do not deliver a file that failed a gate without telling the user. |
| Session tab does not show the video | Share the file path, and show the poster PNG and the proof sheets instead. |
| Out of time before the file is ready | Hand over only what is verified, such as a shorter cut or the GIF preview of a checked file, and put everything still open under Weak spots in the report (`delivery.md`). |

## Platform notes

| | Windows | macOS | Linux |
|---|---|---|---|
| ffmpeg | `winget install Gyan.FFmpeg` (a build with libx264) | `brew install ffmpeg`; Homebrew's folders are searched even when not on PATH | the distribution's package; some builds leave libx264 out, so check `ffmpeg -hide_banner -encoders` |
| uv | `winget install astral-sh.uv` | the installer from astral.sh, or `brew install uv` | the installer from astral.sh |
| Shell | Claude Code's Bash tool is Git Bash: `cp -r`, `/` paths and `$(...)` work as written | bash or zsh | bash |
| Fonts | Arial in `C:/Windows/Fonts` is found first | Arial or Helvetica in the system folders | `engine.FONT_BOLD` lists the usual Liberation Sans and DejaVu Sans folders; with none installed, `font()` raises and says what to install |
| Voice | sapi (robotic) and kokoro-ts, both tested on Windows 11 | kokoro-ts, untested on macOS | kokoro-ts, untested on Linux |
| Locks | A folder that is any process's working folder cannot be moved or deleted | none met | none met |

On every platform the render spawns fresh worker processes (never forks), so everything a build runs must sit under `if __name__ == "__main__":`, as `run_all.py` does, and scenes.py must read the frame size only when it is imported.

## Lessons from past builds

Each line is a failure we hit, what caused it, and what the engine does now.

1. **A 9:16 piece came out at 16:9.** Render workers start as fresh processes on Windows (and the engine spawns them on every platform), so a module that imported scenes at its top read the default 1920x1080 before the worker had set the size. `render.py` imports scenes inside its functions, after `_start` sets `E.W`, `E.H`, `E.FPS` and `E.SS`, and `run_all.py` keeps its work under `if __name__ == "__main__":`.
2. **Every headline came out tiny.** With the font missing, Pillow quietly fell back to its 10 px default. `engine.font()` now raises `FileNotFoundError` when no listed font file exists, so the build stops instead of shipping the wrong type.
3. **Titles ran out of the safe area at 9:16.** They were sized from the frame width. Size titles from the short side, `min(W, H)`, and fit them with `fit_size` (`craft.md`); Q201 fails the overflow.
4. **The true peak rose after the mix was mastered.** The AAC encode adds true peak: across 9 mixes, up to 1.23 dB at 192 kb/s and at most 0.45 dB at 320 kb/s. So the master limits to -2.0 dBTP, the mux encodes AAC at 320k, and `run_all.py` measures the decoded MP4 and re-masters lower while it reads over -1.3 dBTP (`sound.md`).
5. **Sound effects ran 37 to 87 ms late.** Sync is now measured per cue on the SFX stem, and that showed where the lateness came from: slow attacks placed by their first sample (a 0.25 s pad attack is heard 44 ms in). Place every sound by its landmark with `synth.place` (`align='pad'` for pads and chords).
6. **A voice drifted off its cues.** A 48 kHz voice file was added sample by sample into the 44.1 kHz bed. Played at 44.1 kHz, such a file runs 8.8 percent slow, so a word 10 s in lands 0.88 s late (48000 / 44100). Every module works at 44.1 kHz and only the master writes 48 kHz; decode voice with `voice.dec`, which resamples.
7. **A 60 s film came out at 140.2 MB.** Film grain drives file size: grain std 2.6 gave 140.2 MB for 60 s, std 1.6 at CRF 20 gave 35.9 MB. `grain.grain` now defaults to std 1.6, holds each grain for 2 frames and reuses 4 tiles (`formats.md`).
8. **Parallel renders died with WinError 1450.** Raw 1080p frames (6.2 MB each) sent back from worker processes through a pipe failed in 7 of 45 renders while several builds shared the machine. Frames now travel through a shared-memory ring and only a digest and a thumb go through the pipe: 0 of 40 failed.
9. **A build whose gates all passed crashed while printing.** A redirected Windows console is cp1252, and a caption held an arrow. Every row prints ASCII, with other characters as `\u` escapes (`contract.line`).
10. **A check passed on part of the film.** An ffmpeg decode run without `-nostdin` stopped early, with exit code 0, when a key press was waiting on stdin (200 of 1800 frames were read). Every decode closes stdin and checks its frame count against ffprobe's.
11. **Render workers drew different frames for the same t.** A seed made with Python's `hash()` of a string changes in every process. Seeds come from `zlib.crc32` or from `engine.rng`, and the lint flags `hash()` of a str (Q1202).
12. **A scene lost a frame.** A duration like `5 / 30` is not exact as a float and can land on the wrong side of a half-frame. `compile_schedule` reads every duration as the nearest fraction with a denominator up to 10**6, then rounds each instant once.
13. **A folder could not be moved or deleted (Windows).** A folder that is any process's working folder is locked. Move its contents instead, and keep shells out of the build's subfolders; an approve run from a shell inside `approved/` fails with CANNOT APPROVE for the same reason.
