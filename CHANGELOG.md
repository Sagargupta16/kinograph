# Changelog

Every change, newest first, under the version that shipped it.

## 0.1.1 - 2026-11-01

- **Fixed: a refused build no longer deletes the last one.** `run_all.py audio` checked that the picture still matched `scenes.py`, and `run_all.py full` checked its size budget, only after deleting `out.mp4`, the mixes (and, for `full`, the picture) and rewriting `build.json`. Every refusal now comes first: an audio run at the wrong size and a 0.3 MB budget both left all seven build files byte for byte as they were.
- **Fixed: a cut or damaged file gets a verdict, not a traceback.** When frame 0 or the last frame does not decode, Q501 or Q502 now reads NOT CHECKED, as Q503 already did, and `qa.py check` ends `QA: NOT CHECKED` with exit 2. It used to stop on `ValueError: cannot reshape array of size 0`. A new selftest case, `files.cut`, plants it; the selftest now ends `SELFTEST: PASS (147 fixtures, 58 of 58 codes covered, 0 expected gaps)`.
- **`NO_FFMPEG`** now says every rung of the encode ladder needs ffmpeg, and the builder stops and asks when there is none, instead of being sent to the ladder.
- **The reviewer agent, four references, setup.sh and the README diagram, rewritten from the code.** `agents/reviewer.md`, `references/qa-gates.md`, `references/engine.md`, `references/sound.md`, `references/troubleshooting.md`, `setup.sh` and `docs/praxinoscope-flow.*` are new, written from the engine's code and from runs of the shipped template on 2026-11-01. Every number in them is read from the code (the constant or function is named) or dated to those runs; claims that could not be re-measured were dropped.
- **Reviewer.** The reply block keeps every field `qa.py approve` reads (verdict, `stage:`, `file:` with its written time, `reviewer:`, `frames seen:`), and a final-stage REVIEW PASS in the new format approves the template build. The reviewer now writes its own `qa.py check --json` to `review/qa_<id>.json`, so the builder's `qa.json` (the baseline approve keeps) stays as it was. It reports stale sheets or a `.rejected` or `.unchecked` file as a P0, ranks an undeclared change from `qa.py diff` as P1, and has its own finding codes, `R-STORY` to `R-FILE`.
- **qa-gates.md** gives every one of the 58 codes its module, gate, failure status and real thresholds, which step makes each code (`qa.py check` makes 47 of them), every `qa.py` subcommand with the flags its `--help` lists, and the self test's 2026-11-01 result.
- **engine.md** lists every engine file, the `compile_schedule` rules with each error it raises, the three stages and the lines they print, how the render moves frames, the files a build writes with their `contract.py` names, how to plug in a score of your own, and the encode ladder. Every command in it was run once on the template, including the AV1, VP9 and GIF rungs.
- **sound.md** covers the shared clock, the template score as it really plays (a kick, an off-beat tick and one tone a beat), every `synth.py` instrument with its measured peak, placing a sound by its landmark (a 0.25 s pad placed by its first sample is heard 44.5 ms late, a Q902 FIX), the cue sheet, the beat grid, the mix, the master and the true-peak loop, and silent and narrated pieces.
- **troubleshooting.md** is indexed by the first words of the printed line: setup, the working-folder copy, tracebacks, proof rows, REJECTED and UNCHECKED files, the true-peak loop, render failures, stage refusals, checking a file by hand, every `REFUSED:` and `CANNOT APPROVE` reason, and slow builds and big files. Most quoted lines were reproduced by planting the fault in a copy of the template.
- **setup.sh** finds ffmpeg the way `contract.find_ffmpeg` does, reads the Python version from `engine/.python-version` (no fallback version: a missing file is a FIX line), checks Pillow and numpy against their `requirements.in` pins and asks the engine for its default font. It prints an `ok` or `FIX` line per check and ends `SETUP: PASS`, or `SETUP: FAIL (n to fix, ...)` with exit 1.
- **The README flow diagram** has new lanes, labels and arrows, each citing the file and lines behind it at revision 038f36b, and was exported again as one ASCII SVG with both themes.
- **Docs that disagreed with the code.** README: 47 of the 58 codes run in `qa.py check`, the rest at the proof, in the master, `calib` and `diff`. delivery.md: the template's `QA:` line is 49 checks from `run_all.py full` and 44 from `qa.py check`. builder.md: the layout function is `placed(name, lt)`. styles/README.md and signal.md: the font lines are `FONT_BOLD[:0] = [...]`, since the template has no `E`. formats.md: CRF is set in `run_all.py` (changing `render.CRF` did nothing), and the GIF is 0.80 MB. craft.md: the lowest template contrast at both sizes, and when Q1104 notes a 2-frame gap. SKILL.md: what setup.sh installs and how it ends. Three code comments: `audio.bed`, the pad tolerance in `qa_sync`, and a `qa_lint` pointer to a table that did not exist.

## 0.1.0 - 2026-10-31

First public release.

- **One skill, `/praxinoscope:praxinoscope`.** The main chat takes a brief, offers styles, writes a storyboard that `qa.py holds` checks for reading time, and builds nothing until the user approves it. A proof, a fresh-eyes review and a render follow, then a final review whose verdict `qa.py approve` binds to the file's content hashes.
- **Two agents.** `praxinoscope:builder` writes, renders and checks one video in its own context. `praxinoscope:reviewer` reads only the scenario and the working folder, never the builder's report.
- **Six original styles:** signal (product launch), ledger (data story), blueprint (technical explainer), marquee (logo sting or title card), pulse (beat-locked kinetic type for reels) and cartridge (retro 8-bit parody).
- **The engine.** Every frame is a pure function of time on one integer frame clock. Frames pass from worker processes through a shared-memory ring into a single H.264 encode, tagged BT.709. Sound comes from numpy instruments placed by their perceptual landmark and a 4x oversampled true-peak master to -14 LUFS. Offline narration has word cues.
- **58 coded QA checks** (`qa.py check`), each proven by planted-fault fixtures in `qa.py selftest`.
- **One Python version per build.** `engine/.python-version` (3.15) travels with every copy of the engine, so a proof and its render run on the same interpreter; CI reads the same file.
- **The README flow diagram**, `docs/praxinoscope-flow.svg`: a dual-theme SVG with no scripts or external links. Its archify source, `docs/praxinoscope-flow.workflow.json`, cites the file and lines behind every box.
